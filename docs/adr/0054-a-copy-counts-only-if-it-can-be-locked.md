# 0054. A copy counts only if it can be locked: custodians answer `CHECKPRESENT` with a lock

- **Status:** Withdrawn, 14 October 2026, by the agent, at Guillaume's request
  (chat): moved to the specification.

This record held a rule that the specification now carries: [09 §9.4](../spec/09-network-and-joining.md) and [08 §8.3](../spec/08-custody-loops.md).
Under the [policy](README.md#when-to-write-an-adr) it is not an ADR: it is
a safety invariant (P1) whose alternative counts a copy that is being dropped (E23). Its full text, with its context, evidence and
alternatives, is at [commit 1a6067e](https://github.com/mariogeiger/pigeon/blob/1a6067e/docs/adr/0054-a-copy-counts-only-if-it-can-be-locked.md).
