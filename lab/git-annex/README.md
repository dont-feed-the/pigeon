# git-annex experiments

Shell scripts run against git-annex 10.20261006 (standalone build in
`~/git-annex.linux`), each in its own lab directory under `~`. E23 and E25 also
run against pigeon's patched build ([`third_party/git-annex/`](../../third_party/git-annex/),
ADR 0069). Results are
summarised in [`docs/design/GIT-ANNEX.md`](../../docs/design/GIT-ANNEX.md) and
in the proposal, §5.

The lab joins CI once its scripts assert (ADR 0026). The `lab` workflow runs every
asserting script, E12/E13, E14, E15, E15b, E18, E19, E20, E21, E22, E23 and E24, on Linux
(the pinned standalone build) and macOS (Homebrew), in four parallel groups (13 §13.8).
Each script isolates git from the person's configuration and sets a lab identity;
a platform difference is printed as `SKIP (platform)` with its reason. The
`git-annex` workflow builds pigeon's git-annex and runs E23 and E25 against it
and, as a negative control that reports without failing, against the stock build.
E25 keeps all 500 fetches for the patched build; the stock control uses
`500 --stop-after-hangs 3` to stop after three hangs, including nonconsecutive
ones. Omit the flag for the longer stock measurement. The flag never shortens
a patched run. Pending:
E11 native Windows.
